### Java SPI



配置文件位置和命名规则：
- 配置文件位置：`META-INF/services/`
- 配置文件命名规则：`<接口全限定名>`

配置文件内容格式：
- 每行一个实现类的全限定名
- 忽略空行和注释



### SPI加载流程
1. ServiceLoader.load()
- 根据接口类名查找配置文件
- 读取META-INF/services/<接口全限定名>文件

2. 解析配置文件
- 读取文件中的每一行
- 忽略空行和注释
- 解析实现类的全限定名

3. 实例化实现类
- 使用反射机制创建实例
- 调用无参构造函数 

4. 返回迭代器
- 返回ServiceLoader迭代器
- 按配置文件中的顺序返回实现
